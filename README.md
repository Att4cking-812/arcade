# Brickyard Arcade 🕹

Мини-игры в браузере: без установки, регистрации и рекламы. Ставится как приложение, работает офлайн.

**Играть:** https://att4cking-812.github.io/arcade/

## Игры

| Игра | Что это |
|---|---|
| 🐍 Змейка | классика с ростом скорости, звуками и топ-5 |
| 💣 Сапёр | три уровня, флажки, таймер, первый клик безопасен |
| 🔢 2048 | стрелки/WASD/свайпы, счёт и рекорд |
| 🪢 Виселица | 20 слов с подсказками, 6 ошибок, экранная клавиатура |
| 🧱 Тетрис | классика с hold, ghost-фигурой, next-очередью и мобильными кнопками |
| 🚢 Морской бой | расстановка флота, ИИ с hunt/target, статистика выстрелов |

## Ещё в аркаде

- 🎡 **Колесо фортуны** (`wheel.html`) — призы или участники, анимация, звук, конфетти и история победителей. Настройка — в отдельной панели ведущего по PIN. Зрителям достаточно публичной страницы.
- 🖼 **Мем-музей** (`memes.html`) — семь экспонатов из личной коллекции сервера, лайтбокс и клавиатурная навигация.
- 🏆 **Турниры** (`tournament.html`) — сетка на вылет на 4/8/16 игроков, правила и ссылки на игры.

## Фичи

- **PWA**: `manifest.webmanifest` + `sw.js` + иконки → установка на телефон/десктоп и офлайн-режим
- **Лидерборд**: общий для всех игр на устройстве (`leaderboard.js`, `localStorage`)
- **Звуки** на Web Audio — без внешних файлов
- **Свайпы** на телефоне (змейка, 2048)
- **Тетрис** с hold, ghost-фигурой, next-очередью и мобильным управлением
- **Морской бой** против ИИ с hunt/target-стратегией
- **Секретный уровень** сапёра: 20×20, 80 мин — открывается кликом по футеру с 🍷
- **Колесо фортуны** умеет два режима: призы (с весами) и участники (равные шансы)
- **Ссылка для зрителей** кодирует конфигурацию колеса прямо в URL — без сервера и базы

## Структура

```
index.html            — хаб с карточками игр, колесом, музеем и турнирами
snake.html            — змейка
minesweeper.html      — сапёр (+ секретный режим ?secret=1)
2048.html             — 2048
hangman.html          — виселица
tetris.html           — тетрис
seabattle.html        — морской бой против ИИ
memes.html            — мем-музей
wheel.html            — публичное колесо фортуны
tournament.html       — правила турниров
leaderboard.js        — локальный лидерборд
manifest.webmanifest  — PWA-манифест
sw.js                 — service worker
icon-192.png / icon-512.png
memes/                — картинки для музея
```

Панель ведущего — отдельная страница, в структуру аркады не ссылается и закрыта PIN. PIN знают только владелец сервера и создатель бота.

## Как добавить игру

1. Создай `newgame.html` в той же папке.
2. Добавь карточку в `index.html`.
3. Подключи `leaderboard.js` и при результате вызывай `lbSubmit('newgame', lbName(), score)`.
4. Добавь файл в `ASSETS` в `sw.js`, чтобы он работал офлайн.
